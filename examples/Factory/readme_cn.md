# Factory 工厂测试示例

[English](readme.md)

`Factory.ino` 是 T-Glass V3 的整机工厂测试固件，用于快速检查摄像头、屏幕、触摸按键、BOOT 按键、扬声器、麦克风、时间、LoRa、电池和 Wi-Fi，并支持调整和保存显示区域位置。

## 使用前准备

1. 连接与测试频段匹配的 LoRa 天线和测试电池。
2. 使用 USB 数据线连接电脑，串口波特率为 `115200`。
3. 开启以下至少一个 Wi-Fi 热点：

   | SSID | 密码 |
   | --- | --- |
   | `xinyuandianzi` | `AA15994823428` |
   | `LilyGo-AABB` | `xinyuandianzi` |

4. 给设备上电。固件连接 Wi-Fi 后进入 T0 摄像头页面；两个热点均不可用时，固件会停留在等待连接状态。

## 页面和功能

短触触摸按键切换到下一页，每次换页会播放提示音。

| 页面 | 显示内容 | 测试功能 |
| --- | --- | --- |
| T0 | 摄像头实时画面 | 摄像头、屏幕 |
| T1 | `Mic Level` | 麦克风左右声道 |
| T2 | 时间、星期、月份 | Wi-Fi/NTP 时间显示 |
| T3 | `LoRa Tx` | LoRa 周期发送 |
| T4 | `LoRa Rx` | LoRa 接收、RSSI、SNR |
| T5 | `Volts` | 电池电压和电量 |
| T6 | `RSSI` | Wi-Fi 连接和信号强度 |
| T7 | 四方向动态图 | 图像和动画显示 |
| T8 | `Screen Move` | 显示区域位置校准 |

## 按键操作

- **触摸按键**：T0 至 T7 切换下一页；T8 未进入调整模式时返回 T0。
- **BOOT 单击**：仅在 T8 调整模式下切换 `UP -> DOWN -> LEFT -> RIGHT`。
- **BOOT 双击**：在 T8 进入调整模式；调整完成后再次双击，保存位置并返回 T0。
- **BOOT 长按**：显示 `Sleep.` 后进入休眠，短触触摸按键唤醒。

### T8 屏幕位置校准

1. 切换到 T8，双击 BOOT，标题由 `Screen Move` 变为 `Adjusting`。
2. 单击 BOOT 选择移动方向。
3. 短触触摸按键，每次向当前方向移动 5 个单位。
4. 双击 BOOT 保存位置并退出。
5. 重新上电后，已保存的位置会自动恢复。

横向和纵向偏移范围均为 `-63` 至 `63`。

## LoRa 对测

LoRa 测试需要另一台参数一致的对测设备。以启动串口日志显示的实际频率、带宽、SF、CR、同步字和前导码为准。

- T3 页面周期发送 `Hello #n`，必须在对测设备上确认实际收到数据。
- T4 页面显示收到的数据、RSSI 和 SNR。
- LoRa 参数会保存在 NVS 中，串口修改后重启仍然生效。

## 常用串口命令

| 命令 | 功能 |
| --- | --- |
| `next` | 切换下一页 |
| `send` | 切换到 LoRa Tx |
| `recv` | 切换到 LoRa Rx |
| `wifi` | 扫描附近 Wi-Fi，随后自动恢复连接 |
| `touchRead` | 读取触摸原始值 |
| `freq:<MHz>` | 设置 LoRa 频率 |
| `bw:<kHz>` | 设置 LoRa 带宽 |
| `sf:<值>` | 设置扩频因子 |
| `cr:<值>` | 设置编码率 |
| `sw:<十进制>` | 设置同步字，例如 `sw:18` 表示 `0x12` |
| `tp:<dBm>` | 设置发射功率 |
| `pl:<值>` | 设置前导码长度 |

完整测试步骤和合格标准见 [factory_test_guide_cn.md](test/factory_test_guide_cn.md)。
